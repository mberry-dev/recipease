# Recipease

A recipe-based e-commerce web app that turns ingredients into a shoppable cart.

## About
Recipease lets users browse recipes and automatically adds the required ingredients to a shopping cart — making meal planning and grocery shopping seamless.

## Features
- Browse and search recipes
- Auto-populate shopping cart from recipe ingredients
- Clean, responsive UI

## Built With
- HTML, CSS, JavaScript

## How to Run
1. Clone the repo
2. Open `index.html` in your browser
